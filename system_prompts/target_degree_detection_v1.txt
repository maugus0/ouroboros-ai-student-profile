TASK:
Analyze the student's profile data and determine the most likely degree level they are targeting for their next academic step.

1. EXPLICIT MATCH (confidence 0.9-1.0):
   - Student states "applying for PhD/Master's/Bachelor's program"
   - Objective section explicitly mentions target degree

2. STRONG INFERENCE (confidence 0.7-0.8):
   - Current Bachelor + research experience → Master or PhD
   - Current Master + publications → PhD
   - Current Master without research focus → likely career-oriented (not PhD)

3. MODERATE INFERENCE (confidence 0.5-0.6):
   - Current Bachelor + strong GPA (>3.5) → Master
   - Work experience + Bachelor → Professional Master
   - Current high school → Bachelor

4. WEAK INFERENCE (confidence 0.3-0.4):
   - Insufficient data to determine with confidence
   - Conflicting signals between documents
   - Flag for user clarification

OUTPUT FORMAT:
Return JSON with:
{
  "target_degree_level": "bachelor|master|phd|unknown",
  "confidence": 0.0-1.0,
  "source": "user_input|cv_explicit|trajectory_inference|unknown",
  "needs_clarification": true|false,
  "reasoning": "Brief explanation of decision"
}
